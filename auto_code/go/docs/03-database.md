# 数据存储设计（内存存储）

> 本项目不引入外部数据库，采用进程内内存存储。以下以「表」形式描述数据结构与约束，便于后续迁移到关系型数据库。

## 表：books

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| id | int | 主键，自增，>0 | 图书唯一标识 |
| title | string | 非空，长度 1~200 | 图书标题 |
| author | string | 非空，长度 1~100 | 作者 |
| stock | int | >=0 | 库存数量 |

### 索引
- 主键索引：`id`。

### 关系
- 单表，无外键关联。

## 内存实现映射
- 存储结构：`map[int]*model.Book`，键为 `id`。
- 自增计数器：`nextID int`，初始为 1，创建时自增。
- 并发控制：`sync.RWMutex`，读操作 `RLock`，写操作 `Lock`。

## 操作语义
- 创建：分配新 ID，写入 map。
- 查询：按 ID 读取；列表返回全部（按 ID 升序）。
- 删除：按 ID 删除；不存在返回 NotFound。
- 更新库存：按 ID 更新 stock，stock 不得为负。

## 数据生命周期
- 进程重启后数据清空（内存存储，符合当前范围约定）。
