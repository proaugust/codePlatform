# 数据存储（内存存储）

> 沿用现有内存存储方式，不引入数据库。以下为逻辑表结构描述。

## 表：books

| 字段 | 类型 | 约束 | 说明 |
| --- | --- | --- | --- |
| id | int64 | 主键，自增，> 0 | 图书唯一标识 |
| title | string | 非空，长度 1~200 | 书名 |
| author | string | 非空，长度 1~100 | 作者 |
| stock | int | >= 0 | 库存数量 |
| created_at | time.Time | 非空 | 创建时间 |

## 关系
- 单表，无外键关联。

## 并发与一致性
- Repository 使用 `sync.RWMutex`：读操作加读锁，写/删除操作加写锁。
- 删除按 `id` 匹配，命中则从切片/映射移除；未命中返回不存在错误。
- 自增 ID 由存储内部维护，删除后不复用。
