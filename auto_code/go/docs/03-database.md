# 数据库（内存存储模型）

> 本工程沿用内存存储，不引入数据库。以下为内存数据结构定义，等价于表结构。

## 表：books

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| id | int | 主键，自增，唯一 | 图书标识 |
| title | string | 非空 | 书名 |
| author | string | 非空 | 作者 |
| stock | int | >= 0 | 库存数量 |
| created_at | time.Time | 非空 | 创建时间 |

## 关系
- 单表，无外键关系。

## 并发与一致性
- 使用 `sync.RWMutex` 保护读写；删除操作加写锁。
- 删除不存在 ID 返回「未找到」错误，由 Handler 映射为 404。
- ID 自增计数器在写锁内递增，保证唯一。
